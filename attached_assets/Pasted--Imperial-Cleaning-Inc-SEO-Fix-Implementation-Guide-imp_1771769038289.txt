# Imperial Cleaning Inc - SEO Fix Implementation Guide
## imperialcleaninginc.com | Next.js Codebase
## For Developer Implementation in Replit

---

## CONTEXT

This is a Next.js website for a commercial cleaning and construction cleaning company serving Idaho and Utah. The site was recently rebuilt from WordPress to Next.js, and the migration broke SEO in several critical ways. This document contains all the fixes that need to be implemented.

The site's live sitemap is at https://imperialcleaninginc.com/sitemap.xml and contains 57 URLs covering core pages, Idaho city pages, and Utah city pages.

---

## FIX 1: RESTORE THE NAVIGATION MENU

The site's navigation menu is not rendering. Find the header/navbar component and ensure it is properly imported and rendered in the root layout (`app/layout.tsx` or `src/app/layout.tsx`).

The navigation must include these links using Next.js `<Link>` components from `next/link`:

## FIX 3: INTERNAL LINKING

Every page on the site must have proper internal links to related pages. All internal links must use the Next.js `<Link>` component from `next/link`, never plain `<a>` tags. Anchor text should naturally incorporate target keywords (commercial cleaning, janitorial services, construction cleaning, construction cleanup, post-construction cleaning) combined with city/state names where appropriate.

The homepage body content (not just the nav/footer, but within the actual page content) must contain contextual links to:

### 3F: City Page Internal Links (applies to ALL 48 city pages)

Every city page needs these links:

**Link UP to parent pages:**
```
/                                   anchor: "Imperial Cleaning" or "Home"
/commercial-cleaning                anchor: "commercial cleaning services" (if this is a commercial page)
/construction-cleaning              anchor: "construction cleaning services" (if this is a construction page)
/service-areas/idaho                anchor: "Idaho service areas" (if Idaho city)
/service-areas/utah                 anchor: "Utah service areas" (if Utah city)
```

**Link ACROSS to the sibling service type for the same city.** For example:
```
If page is /idaho/commercial-cleaning/idaho-falls:
  -> link to /idaho/construction-cleaning/idaho-falls   anchor: "Idaho Falls construction cleaning"

If page is /idaho/construction-cleaning/idaho-falls:
  -> link to /idaho/commercial-cleaning/idaho-falls     anchor: "Idaho Falls commercial cleaning"
```

This applies to every city page. The commercial version links to the construction version of the same city, and vice versa.

## FIX 4: DUPLICATE CONTENT CHECK ON CITY PAGES

Review all 48 city pages for duplicate content blocks within individual pages. The Blackfoot commercial cleaning page has a section ("Food Processing Facility Cleaning in Blackfoot") that appears twice with identical text. If other city pages have similar duplicate blocks, remove the duplicates.

Also verify that each city page has at least some content that is unique to that specific city and not just the city name swapped into an otherwise identical template. Pages that are 95%+ identical across cities will be treated as thin/duplicate content by Google and may not be indexed.
