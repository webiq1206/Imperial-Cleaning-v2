# Citation Audit & Fix List

NAP (Name, Address, Phone) consistency across third-party directories is a core local ranking signal. The audit found inconsistencies that need manual fixes - these are external sites, so only the owner can correct them.

## Canonical NAP - use this exact format on every listing

| Field | Value |
| --- | --- |
| Name | Imperial Cleaning Inc |
| Street | 2653 Clarence Pl |
| City/State/ZIP | Idaho Falls, ID **83402** |
| Phone | (208) 520-3202 |
| Website | https://imperialcleaninginc.com |
| Email | service@imperialcleaninginc.com |
| Founded | 2015 |
| Category | Commercial cleaning service / Construction cleaning |

The website, schema, and llms.txt now all use 83402 - external citations must match.

## Known issues found during the audit (fix first)

- [ ] **ZIP inconsistency:** some citations show 83404, others 83402. Correct every listing to **83402**.
- [ ] **Hours:** Google lists Mon-Fri 8AM-5PM, Sat 9AM-1PM, Sun closed. The website now matches Google. Fix any citation still showing the old 7AM-6PM / 8AM-4PM schedule.
- [ ] **Business-type drift:** some listings describe the company as residential/house cleaning. Set category to commercial/construction cleaning wherever the directory allows.
- [ ] **Secondary phone numbers:** if any listing shows a number other than (208) 520-3202, remove it or set it as secondary - the main line must be consistent.

## Tier 1 - claim/fix these first (highest weight)

- [ ] Google Business Profile - see gbp-optimization.md
- [ ] Bing Places (bingplaces.com) - import from GBP, then verify NAP
- [ ] Apple Business Connect (businessconnect.apple.com) - critical for iPhone/Siri/Apple Maps
- [ ] Yelp - claim listing, set categories, correct ZIP
- [ ] Facebook business page - confirm NAP in About section matches exactly
- [ ] Nextdoor business page - high trust signal for local service businesses

## Tier 2 - existing profiles found during the audit (verify NAP)

- [ ] Porch (pro.porch.com) - profile exists with reviews; confirm ZIP 83402 and phone
- [ ] BestProsInTown - profile exists with rating; verify details
- [ ] LinkedIn company page - confirm Idaho Falls HQ, founded 2015, website link

## Tier 3 - industry & local directories (build over time)

- [ ] BBB (bbb.org) - accreditation optional, but a free listing with correct NAP helps
- [ ] Angi / HomeAdvisor - commercial categories where available
- [ ] Thumbtack - commercial cleaning category
- [ ] Idaho Falls Chamber of Commerce - membership includes a directory listing (also a real local link)
- [ ] Greater Pocatello Chamber / Rexburg Chamber - same, for secondary markets
- [ ] Utah listings: Salt Lake Chamber or a Logan/Cache Valley directory to support Utah pages
- [ ] AGC of Idaho (Associated General Contractors) - directory listing puts you in front of GCs, the actual buyers of post-construction cleaning

## How to work through this list

1. Fix Tier 1 + the known issues in one sitting (~2 hours).
2. Do Tier 2 verification the same week.
3. Add 1-2 Tier 3 listings per month - steady growth looks natural.
4. Keep a spreadsheet: directory, URL of your listing, login email, date verified. Re-check every 6 months - aggregators silently overwrite data.

## What NOT to do

- Do not buy bulk citation packages (500 directories etc.) - low-quality directories add no value and create cleanup work.
- Do not vary the business name to inject keywords ("Imperial Cleaning - Best in Idaho Falls").
- Do not list a street address publicly unless customers can actually visit it; use service-area settings instead.
