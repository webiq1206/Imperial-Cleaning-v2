# Google Business Profile — Products catalog

Every service Imperial Cleaning offers, written up as a Business Profile
**Product**, ready to paste. Construction cleaning is covered in the most
depth because it is the highest-value line and the one with measured search
demand that currently earns zero clicks.

Products are managed only in the Business Profile editor. There is no API for
them, so this is a paste job: **Edit profile → Products → Add product**, one
entry at a time.

## Field limits (check these in the editor before pasting — Google adjusts them)

| Field | Limit / rule |
|---|---|
| Product name | 58 characters. Every name below fits. |
| Category | Free text, one per product. Products with the same category are grouped into one tile row. Use exactly the five categories below so the grouping is clean. |
| Price | Optional. A single figure or a range. Ranges below are the ones already published on the website — do not invent others. |
| Description | 1,000 characters. Every description below is 650–950 so it fits with room. |
| Photo | Required. JPG or PNG, minimum 720 × 720. Tiles crop to a square, so supply **1200 × 1200** and keep the subject centred. |
| Button | Use **Learn more** with the URL given. Every product links back to the website. |

**Order matters.** The profile shows products in the order you add them and
surfaces the first few most prominently. Add them in the order listed here:
construction first, then core commercial, then facility types.

## Photos — real ones only

Product photos are the single biggest driver of whether a tile gets tapped, and
the fastest way to get a product rejected is a stock image or an AI render with
text baked in. Every photo below should be **your crew, your equipment, your
jobsite**. If a photo does not exist yet, take it before publishing that
product — do not substitute.

Rules for every shot:

- 1200 × 1200 JPG, under 5 MB, subject centred so the square crop keeps it
- Daylight or well-lit interior; no heavy filters
- No text, logos, phone numbers, or watermarks laid over the image — Google
  down-ranks or rejects text-heavy product images
- No client names, signage, or identifiable branding of the buildings you clean
  unless you have written permission
- Faces are fine and perform better than empty rooms, with the crew's consent

One consistent brand element you *can* use: a uniformed crew member in frame.
It reads as real, ties the catalogue together, and never gets flagged.
