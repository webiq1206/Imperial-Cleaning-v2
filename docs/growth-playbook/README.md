# Imperial Cleaning Inc | 2026 Growth Playbook Operating System

This folder is the live execution system for the **Imperial Cleaning Inc Master Growth Playbook 2026** (PDF, September 1, 2026). The PDF is the strategy source: positioning, channel mix, keyword priorities, and the 30/60/90 roadmap. These markdown files are what the owner and web team update weekly so execution stays honest and measurable.

Do not treat the PDF as a checklist you read once. Treat this folder as the operating system you run every week.

## Current execution authority

Read [AUTONOMOUS-GROWTH.md](./AUTONOMOUS-GROWTH.md) and [the October 1 execution receipt](./execution-2026-10-01.md) first. The current program authorizes relevant free autonomous execution, preserves factual proof requirements, and excludes paid acquisition. Historical owner-only labels are access limitations to reassess, not routine approval gates.

## How to use this system

1. Read the PDF once for context and priorities.
2. Start with [completion-status.md](./completion-status.md) to see what is done, partial, or owner-only.
3. Before publishing any new claim on the website, ads, GBP, or outbound, add it to [proof-ledger.md](./proof-ledger.md).
4. Run the weekly scorecard in [scorecard.md](./scorecard.md) and update trackers monthly.
5. Follow owner checklists in [`../owner-checklists/`](../owner-checklists/) for work that cannot be done in code.
