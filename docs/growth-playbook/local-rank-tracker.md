# Local Rank Tracker

Track organic rank and map-pack position by city and keyword. Fill monthly (or weekly for Tier 1 markets during active campaigns).

**How to measure organic rank:** Search in incognito or a rank tool using the exact keyword plus city where applicable (e.g. `commercial cleaning Idaho Falls`). Record position for imperialcleaninginc.com.

**How to measure map-pack:** Search the local keyword on mobile or Local Falcon / similar grid tool. Record position 1-3 or "not in pack". Note which GBP listing surfaced.

**GBP surfaced:** Y if Imperial Cleaning Inc Idaho Falls listing appears; N if not.

---

## Instructions

1. Pick a consistent time of day and device for manual checks.
2. For map-pack, search from the target city or use a geo-grid tool centered on the city.
3. In **Competitor above**, name the business ranking above Imperial (organic or map).
4. Do not chase rankings for cities where operations cannot service profitably.
